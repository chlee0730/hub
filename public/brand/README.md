# 브랜드 이미지

아래 파일명으로 넣으면 자동으로 표시됩니다. 없으면 해당 영역만 숨겨집니다.

| 파일명 | 내용 | 위치 | 권장 |
|---|---|---|---|
| `signature.png` | 한국공학대학교 시그니처(가로형) | 상단 바 | 투명 배경, 높이 120px 이상 |
| `symbol.png` | 심벌마크 | 요약 영역 배경 워터마크 | 투명 배경, 정사각형 |
| `tino.png` | 마스코트 티노 | 제목 우측, 검색결과 없음 화면 | 투명 배경, 높이 400px 이상 |

출처: 한국공학대학교 홈페이지 > 대학소개 > UI (심벌 · 시그니처 · 티노)
